# Astralyn — Roadmap

## v0.0 — foundation

- repo bootstrap & tooling;
- design tokens & HSR panel primitives;
- D1 canonical schemas & Drizzle ORM;
- Cloudflare Worker + D1 setup;
- Better Auth (Google OAuth);
- source-adapter contracts;
- first official knowledge snapshot;
- recommendation engine skeleton.

## v0.4 — sync/convenience

Evaluate:
- stronger PWA/offline;

## v1.0 criteria

- ingestion survives a complete HSR patch transition;
- adapters degrade safely;
- recommendations are reproducible;
- core modules work without paid AI;
- accessibility baseline passes;
- mobile/desktop UX polished;
- source attribution consistently visible.

## Later / evaluate carefully

- warp data;
- achievements;
- community builds.
